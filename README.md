# 新标签页导航（Chrome / Edge 浏览器插件）

一个简洁美观的新标签页导航插件，基于 Chrome Manifest V3 开发。支持问候语、智能搜索、分类书签网格、本地图片背景、彩色网状粒子动效、明暗主题，以及基于 **S3 对象存储** 的跨设备配置同步。

> 兼容 Chrome / Edge / Brave 等 Chromium 内核浏览器。

---

## 功能特性

- **智能问候 + 实时时钟**：按时间段显示“早上好 / 下午好”等问候，右上角实时时钟
- **智能搜索栏**：输入网址直接跳转，输入关键词调用浏览器默认搜索引擎；图标自动匹配当前搜索引擎
- **分类书签网格**：仿 macOS 悬浮卡片风格，favicon 自动抓取，失败时按名称生成彩色字母图标
- **书签管理**：可添加 / 编辑 / 删除书签，分类可重命名 / 删除；支持一键导入浏览器已有书签（可选包含其它设备同步来的书签）
- **本地图片背景**：可选本地图片作为背景，图片透明度 0–100% 可调
- **彩色网状粒子动效**：鼠标附近粒子自动连线，线条颜色渐变（可开关）
- **纯背景模式**：一键隐藏所有图标只显示背景（快捷键 `H`）
- **明暗主题**：太阳 / 月亮按钮一键切换
- **跨设备同步**：通过 S3 兼容对象存储（MinIO / AWS S3 等）同步整份配置，用「邮箱」区分不同用户
- **数据本地化**：所有配置保存在 `chrome.storage.local`

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目根目录（包含 `manifest.json` 的文件夹）
4. 打开一个新标签页即可看到效果

## 使用说明

### 搜索
- 输入网址（如 `github.com`）回车 → 直接跳转
- 输入关键词 → 使用浏览器默认搜索引擎搜索
- 快捷键 `/` 快速聚焦搜索框

### 书签管理
- 点击右上角 ⚙️ 进入设置面板
- 「分类与书签」中可展开每个分类，进行添加书签、重命名、删除分类等操作
- 添加书签时可点「📂 从浏览器书签选择」，一键读取浏览器已保存的书签

### 跨设备同步（S3 对象存储）

设置面板「同步（对象存储 / S3）」中填写：

| 字段 | 说明 |
| ---- | ---- |
| Endpoint | S3 服务地址，如 `https://backup.example.com` |
| Bucket | 存储桶名称 |
| Access Key | 访问密钥 |
| Secret Key | 私有密钥 |
| 邮箱 | 用于区分不同用户（留空则共用默认文件） |

- 「测试连接」验证配置；「上传配置」把当前配置存到云端；「下载配置」从云端还原
- 填好配置后，任何改动会**自动上传**（2 秒防抖）
- 不同用户填不同邮箱，会存为 `newtab-config-{邮箱}.json`，互不覆盖

### 「多设备同步」开关

设置面板顶部的「多设备同步」开关控制：添加书签时「从浏览器书签选择」是否**包含 Chrome 账号同步到本机的其它设备（手机/平板）书签**。

### 背景与外观
- 「背景图片」中可选择本地图片作为背景，并调节图片透明度
- 「彩色网状粒子动效」开关控制背景粒子动画
- 右上角 ☀️/🌙 切换明暗主题，👁 切换纯背景模式

### 快捷键

| 快捷键 | 功能 |
| ------ | ---- |
| `/`    | 聚焦搜索框 |
| `S`    | 打开设置面板 |
| `H`    | 切换纯背景模式（隐藏图标） |
| `Esc`  | 关闭弹窗 / 设置面板 |

## 自定义

### 修改默认导航
编辑 `data.js` 中的 `DEFAULT_DATA` 数组，然后在插件设置面板点击「导入默认导航」即可生效。数据结构：

```js
[
  {
    name: "分类名",
    items: [
      { name: "站点名", url: "https://example.com" }
    ]
  }
]
```

### 调整粒子动效
编辑 `particles.js` 顶部的 `dots` 配置：

- `nb`：粒子数量（默认 140，越大越密、越耗性能）
- `distance`：连线最大距离（默认 110）
- `d_radius`：鼠标作用半径（默认 150）

### 修改 S3 默认 Region
`s3.js` 及 `app.js` 中默认使用 `us-east-1`（MinIO 默认）。如果你的 S3 使用其它 Region，可修改 `app.js` 里 `getS3Config()` 的 `region` 字段。

## 权限说明

| 权限 | 用途 |
| ---- | ---- |
| `storage` | 保存书签、主题、背景等配置 |
| `unlimitedStorage` | 存储本地背景图片（避免超出默认配额） |
| `favicon` | 自动抓取站点 favicon |
| `history` | 自动检测当前默认搜索引擎 |
| `search` | 调用浏览器默认搜索引擎搜索 |
| `bookmarks` | 读取浏览器已保存书签（导入功能） |
| `host_permissions` | 访问 S3 对象存储接口（跨设备同步） |

## 常见问题

**Q：底部出现“由 Google 提供支持 / 自定义 Chrome”横条？**  
这是 Chrome 浏览器自身注入的 UI，不是本插件产生。可到 `chrome://settings/appearance` 关闭相关选项，或在 `chrome://flags/#customize-chrome-side-panel` 设为 Disabled。

**Q：同步到 MinIO 的配置文件在哪里？**  
在存储桶内，对象名为 `newtab-config-{邮箱}.json`（邮箱留空则为 `newtab-config.json`）。物理上位于 MinIO 数据目录 `<数据目录>/<Bucket>/` 下，不建议直接修改。

**Q：改了文件后没有生效？**  
到 `chrome://extensions/` 点击插件下方的「重新加载」按钮，再刷新新标签页。
